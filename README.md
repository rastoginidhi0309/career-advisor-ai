# AI for Career Prediction & Upskilling Advisor

AI-powered Career Prediction & Upskilling Advisor built with Flask.

This web app predicts the most suitable career based on user scores in:
- Technical Skill
- Logical Reasoning
- Creativity
- Teamwork

It also recommends relevant upskilling courses based on the predicted career.

---

## 🚀 Features

- User inputs skill scores (0‑10)
- Career prediction using simple scoring logic
- Upskilling course suggestions
- Built with Flask (Python), HTML & CSS
